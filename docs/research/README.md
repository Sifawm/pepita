# Research: habit-building apps (November 2026)

Comparison of 16 apps, organized by feature. Anything that couldn't be verified is marked as **"unconfirmed"**. Prices are from the US App Store.

## Apps analyzed

| App | Main focus |
|---|---|
| **Atoms** | Official *Atomic Habits* app: identity, time and place, lessons from James Clear |
| **Habitica** | Role-playing game with peer pressure |
| **Streaks** | Apple tracker with automatic logging from Health; one-time purchase |
| **Finch** | Self-care pet, no punishment |
| **Way of Life** | Yes/no/skip grid, minimal |
| **Fabulous** | Narrative coach with *Journeys* and routines |
| **Productive** | Polished tracker organized by time of day |
| **Habitify** | The most complete rules model and integrations |
| **HabitNow** | Habits and tasks on Android; one-time purchase |
| **Loop** | Open source; "habit strength" |
| **Beeminder** | Escalating money commitment; akrasia horizon |
| **stickK** | Commitment contract with a referee and anti-charity |
| **Strides** | Habits and goals with a *pace line* |
| **TickTick** | Habits module inside a task manager |
| **Routinery** | Sequential routines with a timer |
| **HabitShare** | Social with per-habit privacy |

## What from the book the market covers and what it doesn't

| Book concept | Who covers it | Gap |
|---|---|---|
| Identity | Only Atoms (and superficially) | **Large** |
| Implementation intention | Only Atoms (time and place) | Medium |
| Habit stacking | Habitify (by event), Routinery and Fabulous (sequence), Atoms | Small |
| Environment design | Nobody (only lessons) | **Large** |
| Temptation bundling | Nobody (Habitica *Rewards*, loosely) | **Large** |
| Two-minute rule | Atoms ("starting size") | **Large** |
| Goldilocks / scaling difficulty | Atoms (suggestions) | Medium |
| Habit tracking | All of them | — |
| Never miss twice | Atoms, Streaks (optional) | Small |
| Habit contract | stickK, Beeminder (with money) | Medium (without money: large) |
| Accountability partner | Finch and Habitica (well), Atoms (empty) | Medium |
| Breaking habits (inverse laws) | "Negative" types without a method | **Large** |
| Review and reflection | Finch, Fabulous (generic wellbeing) | Medium |

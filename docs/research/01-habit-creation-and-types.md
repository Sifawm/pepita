# 01 · Habit creation and types

**Principles from the book it touches:** 3rd law (Make it easy: two-minute rule, start small), Goldilocks rule (scaling difficulty), systems before goals, inverse laws (breaking habits).

## Market patterns

- **There are three unit models.** Standalone habit (most), routine or sequence (Fabulous, Routinery) and quantitative goal with a rate (Beeminder, Strides).
- **Bad habits.** Either they have their own type (Habitify, Streaks, Way of Life, Beeminder *Do Less*, Loop *at most*) or they're rephrased positively (Loop, Fabulous).
- **Flexible frequencies ("X times per period").** Almost all have them. Those that don't get complaints.
- **The two-minute rule as an explicit field doesn't exist in any app.** Atoms gets close with "starting size".

## Gaps and opportunities with respect to the book

- A **minimum version (2 minutes)** field versus the **full version**. Count doing the minimum as met ("showing up").
- **Goldilocks** scaling: propose raising the difficulty when the completion rate stays high for N weeks, and lowering it if it drops.
- For breaking habits, frame the **4 inverse laws** as setup steps: which cue you'll remove, which friction you'll add.

# 13 · Onboarding

**Principles from the book it touches:** the two-minute rule applied to the app itself (the first habit has to be ridiculously easy), identity from the start, habit scorecard.

## How each app handles it

| App | Flow |
|---|---|
| **Atoms** | No account or card. **Guided first-habit wizard** with suggestions based on interests, values and goals: action → time and place → identity → starting size. Designed to be used about 5 minutes a day in the morning |
| **Fabulous** | Focus and health questionnaire → **commitment to 3 goals** (checking boxes to reinforce the commitment, not to personalize) → account → **aggressive trial offer** (according to Healthify it can't be skipped) → first routine. **The first habit is drinking water for everyone** |
| **Finch** | **Your pet hatches and you name it** → questions → suggested goals. Automatic 3-day Plus trial. Guide for new users |
| **Habitica** | Create an avatar → choose categories → example tasks → tutorial with a guide character |
| **Beeminder** | Wizard that turns a sentence ("I want to do X") into a goal type, rate and units |
| **stickK** | Wizard: goal → deadlines → stake → referee → supporters |
| **Way of Life** | Interactive welcome tour |
| **Productive** | Beginner *Habit packs* + early paywall |
| **Habitify** | You can configure and link the account later |
| **Loop** | None: empty screen and a "+" button |
| **Streaks, Strides, Routinery** | Suggestions or templates |
| **TickTick** | The habits module **comes disabled on desktop** |

## Market patterns

- **Two styles:**
  1. Long, emotional onboarding ending in a paywall (Fabulous, Finch, Productive).
  2. Minimal (Loop, Streaks).
- Aggressive paywalls in onboarding generate strong complaints (Fabulous).
- What fits the book best is Atoms' first-habit wizard. **A single habit to start** (Fabulous also does it with Journeys).

## Gaps and opportunities

- Start with the **identity** ("who do you want to be?") → **a single habit** → its **2-minute version** → **implementation intention or stacking** → first log **today**.
- Optional habit scorecard for those who want to go deeper.
- Let it be used without an account and without a paywall until the person has seen value.

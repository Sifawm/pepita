# 13 · Onboarding (primeros pasos)

**Principios del libro que toca:** regla de los 2 minutos aplicada a la propia app (el primer hábito tiene que ser ridículamente fácil), identidad desde el principio, tabla de hábitos.

## Cómo lo resuelve cada app

| App | Flujo |
|---|---|
| **Atoms** | Sin cuenta ni tarjeta. **Asistente guiado del primer hábito** con sugerencias según intereses, valores y metas: acción → hora y lugar → identidad → tamaño inicial. Pensada para usarla unos 5 minutos al día por la mañana |
| **Fabulous** | Cuestionario de focos y salud → **compromiso con 3 metas** (marcar casillas para reforzar el compromiso, no para personalizar) → cuenta → **oferta de prueba agresiva** (según Healthify no se puede saltar) → primera rutina. **El primer hábito es beber agua para todos** |
| **Finch** | **Nace tu mascota y le pones nombre** → preguntas → objetivos sugeridos. Prueba Plus automática de 3 días. Guía para usuarios nuevos |
| **Habitica** | Crear avatar → elegir categorías → tareas de ejemplo → tutorial con personaje guía |
| **Beeminder** | Asistente que traduce una frase («quiero hacer X») a tipo de meta, ritmo y unidades |
| **stickK** | Asistente: meta → plazos → apuesta → árbitro → seguidores |
| **Way of Life** | Recorrido interactivo de bienvenida |
| **Productive** | *Habit packs* para principiantes + paywall temprano |
| **Habitify** | Se puede configurar y vincular la cuenta más tarde |
| **Loop** | Ninguno: pantalla vacía y botón «+» |
| **Streaks, Strides, Routinery** | Sugerencias o plantillas |
| **TickTick** | El módulo de hábitos **viene desactivado en el escritorio** |

## Patrones del mercado

- **Dos estilos:**
  1. Onboarding largo y emocional que acaba en un paywall (Fabulous, Finch, Productive).
  2. Mínimo (Loop, Streaks).
- Los paywalls agresivos en el onboarding generan quejas fuertes (Fabulous).
- Lo que mejor encaja con el libro es el asistente del primer hábito de Atoms. **Un solo hábito al empezar** (Fabulous también lo hace con los Journeys).

## Huecos y oportunidades

- Empezar por la **identidad** («¿quién quieres ser?») → **un único hábito** → su **versión de 2 minutos** → **intención de implementación o apilamiento** → primer registro **hoy mismo**.
- Tabla de hábitos opcional para quien quiera profundizar.
- Dejar que se use sin cuenta y sin paywall hasta que la persona haya visto valor.

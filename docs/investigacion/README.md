# Investigación: apps de mejora de hábitos (noviembre de 2026)

Comparativa de 16 apps, organizada por funcionalidad. Lo que no se pudo verificar está marcado como **«sin confirmar»**. Los precios son de la App Store de EE. UU.

## Apps analizadas

| App | Enfoque principal |
|---|---|
| **Atoms** | App oficial de *Atomic Habits*: identidad, hora y lugar, lecciones de James Clear |
| **Habitica** | Juego de rol con presión de grupo |
| **Streaks** | Tracker de Apple con registro automático desde Health; pago único |
| **Finch** | Mascota de autocuidado, sin castigos |
| **Way of Life** | Cuadrícula sí/no/skip, mínima |
| **Fabulous** | Coach narrativo con *Journeys* y rutinas |
| **Productive** | Tracker pulido organizado por momento del día |
| **Habitify** | El modelo de reglas y las integraciones más completas |
| **HabitNow** | Hábitos y tareas en Android; pago único |
| **Loop** | Open source; «fuerza del hábito» |
| **Beeminder** | Compromiso con dinero que va subiendo; akrasia horizon |
| **stickK** | Contrato de compromiso con árbitro y anti-caridad |
| **Strides** | Hábitos y metas con *pace line* |
| **TickTick** | Módulo de hábitos dentro de un gestor de tareas |
| **Routinery** | Rutinas secuenciales con temporizador |
| **HabitShare** | Social con privacidad por hábito |

## Qué del libro está cubierto en el mercado y qué no

| Concepto del libro | Quién lo cubre | Hueco |
|---|---|---|
| Identidad | Solo Atoms (y de forma superficial) | **Grande** |
| Intención de implementación | Solo Atoms (hora y lugar) | Medio |
| Apilamiento de hábitos | Habitify (por evento), Routinery y Fabulous (secuencia), Atoms | Bajo |
| Diseño del entorno | Nadie (solo lecciones) | **Grande** |
| Agrupar tentaciones | Nadie (Habitica *Rewards* de lejos) | **Grande** |
| Regla de los 2 minutos | Atoms («tamaño inicial») | **Grande** |
| Ricitos de Oro / escalar la dificultad | Atoms (sugerencias) | Medio |
| Seguimiento de hábitos | Todas | — |
| Nunca fallar dos veces | Atoms, Streaks (opcional) | Bajo |
| Contrato de hábitos | stickK, Beeminder (con dinero) | Medio (sin dinero: grande) |
| Compañero de responsabilidad | Finch y Habitica (bien), Atoms (vacío) | Medio |
| Romper hábitos (leyes inversas) | Tipos «negativos» sin método | **Grande** |
| Revisión y reflexión | Finch, Fabulous (bienestar genérico) | Medio |
